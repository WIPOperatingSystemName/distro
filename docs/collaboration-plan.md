# Maintainer integration

The organization's [automation guide](https://github.com/WIPOperatingSystemName/.github/blob/main/automation/README.md)
is the reference for controller configuration, static checks, source review and
controlled cross-repository merges. The [shared contribution instructions](https://github.com/WIPOperatingSystemName/.github/blob/main/AGENTS.md)
cover synchronized forks and PR handoff.

Build and boot checks remain required for release qualification; accepted source
review alone does not establish runtime behavior. See the [build guide](build.md)
and [release requirements](release.md). Keep release signing and publication
separate from PR execution.
